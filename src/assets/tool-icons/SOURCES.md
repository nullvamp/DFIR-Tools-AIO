# Tool icon sources

- `capa.png`: `mandiant/capa`, `.github/icon.png`
- `floss.png`: `mandiant/flare-floss`, `resources/floss-icon.png`
- `exiftool.png`: `https://exiftool.org/ET-256.png`
- `plaso.svg`: compact vector treatment of the current Plaso wordmark shown in the project branding
- `yara-x.png`: `VirusTotal/yara-x`, VS Code extension icon
- `apt-hunter.png`: `ahmedkhlief/APT-Hunter`, repository `logo.png`
- `sigcheck.png`: icon extracted from the official Microsoft Sysinternals executable
- `thor-lite.png`: icon extracted from the supplied THOR Lite executable
- `zircolite.svg`: local project tile; Zircolite does not publish a standalone logo asset

The files are bundled into the application and are not loaded from disk or the network at runtime.
